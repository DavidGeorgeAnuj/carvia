# Contributing to CARVIA

## Canonical Repository
The official, canonical repository for this project is:
- **Git Remote:** `https://github.com/DavidGeorgeAnuj/carvia.git`
- **Main Branch:** `main`

## Developer Setup

### 1. Clone & Set Remote
```bash
git clone https://github.com/DavidGeorgeAnuj/carvia.git
cd carvia
```

Ensure your `origin` is set to:
```bash
git remote set-url origin https://github.com/DavidGeorgeAnuj/carvia.git
```

### 2. Git Identity
All contributions should use your verified GitHub identity or match the project configuration:
```bash
git config user.name "Your Name"
git config user.email "your.email@example.com"
```

### 3. Workflow
1. Pull latest changes: `git pull origin main`
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Commit with clear messages: `git commit -m "feat: description"`
4. Push to remote: `git push -u origin feature/your-feature`
5. Open a Pull Request into `main`.
